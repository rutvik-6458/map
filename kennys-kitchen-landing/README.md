# Kenny's Kitchen Landing Page

A modern, mobile-first landing page for Kenny's Kitchen cafe in Vesu, Surat.

## Tech Stack

- Next.js 16 (App Router)
- React 19
- TypeScript
- Tailwind CSS 4
- Framer Motion
- Lucide React Icons

## Getting Started

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) to view the page.

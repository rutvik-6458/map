# Gallery Images Setup

## Required Images

To complete the gallery section, add the following images to the `public/gallery/` folder:

### 1. Cheese-loaded dishes close-up
- **File**: `cheese-dishes.jpg`
- **Description**: Close-up photo of cheesy dishes, showcasing the cheese-loaded menu items
- **Recommended**: High-quality food photography, well-lit, appetizing

### 2. Bunny Chow specialty item
- **File**: `bunny-chow.jpg`
- **Description**: Photo of the signature Bunny Chow (cheesy veggie pizza-sandwich)
- **Recommended**: Professional food styling, showing the dish from an appealing angle

### 3. Tea and coffee beverages
- **File**: `tea-coffee.jpg`
- **Description**: Photo of tea and coffee beverages served at the cafe
- **Recommended**: Clean presentation, showing the variety of beverages

### 4. Cafe interior and seating
- **File**: `interior.jpg`
- **Description**: Interior view showing the cafe's seating and ambiance
- **Recommended**: Wide-angle shot showing the comfortable cafe atmosphere

### 5. Exterior view at Aagam Square Complex
- **File**: `exterior.jpg`
- **Description**: Exterior view of the cafe at Aagam Square Complex
- **Recommended**: Clear view of the cafe entrance and signage

## Image Specifications

- **Format**: JPG or WebP
- **Recommended Size**: 1200x900px (4:3 aspect ratio)
- **Max File Size**: 500KB per image (optimize for web)
- **Quality**: High resolution for crisp display on all devices

## How to Add Images

1. Create the `public/gallery/` folder in the project root (if it doesn't exist)
2. Add all 5 images with the exact filenames listed above
3. The gallery component will automatically load these images
4. If an image is missing, a colored placeholder will be shown

## Image Optimization Tips

- Use tools like [TinyPNG](https://tinypng.com/) or [Squoosh](https://squoosh.app/) to compress images
- Consider using WebP format for better compression
- Ensure images are properly cropped and centered
- Test images on both desktop and mobile devices
